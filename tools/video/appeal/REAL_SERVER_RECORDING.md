## 2. 녹화 — `record-server.mjs` (제가 실행)

```bash
cd /home/user/KPJKcorp; A="STAFF_ID=… STAFF_PW=… CLIENT_ID=… CLIENT_PW=…"   # 계정은 환경변수로만 — 파일 · 로그에 남기지 않는다
env $A OUT=$W/rec-server node tools/video/appeal/record-server.mjs check       # ① 안전 점검만 (서버에 쓰지 않음)
echo '{}' > tools/video/appeal/pauses.json                                    # ② 나레이션을 쉼 없는 원래 속도로
W=$W python3 tools/video/appeal/align_voice.py $W/v2/voice_raw14.wav $W/v2/asr.json
python3 tools/video/appeal/build.py $W --cues                                 #    → $W/cues.json (조작 묶음 사이 간격)
env $A OUT=$W/rec-server CUES=$W/cues.json node tools/video/appeal/record-server.mjs   # ③ 녹화
```

**안전 점검** — 하나라도 걸리면 녹화하지 않고 멈춥니다. 화면이 아니라 서버가 그 계정에 내준 데이터 전체로 봅니다.

| 점검 | 걸리면 |
|---|---|
| 두 창 모두 서버 모드 | 데모 · 브라우저 저장이면 멈춤 |
| 담당자 계정이 받은 기업이 `[가상]` 한 곳뿐 | 실제 고객사가 하나라도 오면 멈춤 (열람 범위 · 담당 확인) |
| 담당자 업무함의 미완료 업무가 모두 그 가상 기업 것 | 다른 업무가 보이면 멈춤 |
| 가상 기업에 진행 중 프로젝트 | 없으면 멈춤 (준비 4) |
| 고객 계정이 그 가상 기업 소속 | 다르면 멈춤 |
| 처음 비밀번호 안내 띠 | 화면에 나오면 멈춤 (준비 6) |

**녹화 방식** — 휴대폰 크기(390×844) 창과 PC(1440×900) 창을 서로 다른 로그인으로 동시에 띄워, 같은 시계로 한 번에 녹화합니다.
한쪽에서 한 일이 다른 쪽에 나타나는 것은 **새로고침 없이** 서버 · 실시간 반영으로만 일어나고, 걸린 시간(초)을 그대로 잽니다.
조작하는 쪽은 발표자가 대본에 맞춰 누르듯 나레이션 큐(`cues.json`)를 따릅니다 — 앞 조작이 늦으면 뒤도 함께 밀립니다.

| # | 화면 | 조작 (사람 속도 · 큐) | 기다리는 것 (새로고침 없이) |
|---|---|---|---|
| 준비 | PC | 지난 촬영의 `… 검토` 업무 완료 처리 → **자료 요청** `법인등기부등본` 1건 | 휴대폰에 새 요청이 뜬다 |
| 1 | 휴대폰 | 업로드 → 예시 PDF → 제출 | PC 업무함에 `… 법인등기부등본 검토` · 자동 |
| 2 | PC | 자동 생성 업무를 가리킨다 → 기업 → 요청자료 → 자료 열기 → 사유 입력 → **보완 요청** | 휴대폰에 **보완필요** |

올리는 파일은 `법인등기부등본_예시.pdf` — 내용은 "예시 파일 — 실제 서류가 아닙니다" 한 줄입니다.

멈추면 그때 두 화면을 `$W/rec-server-{pc,phone}-멈춤.png` 로 남깁니다.

## 3. 영상 반영 — `build.py` 가 알아서

`$W/rec-server/meta.json` 이 있으면 ① 을 그 녹화로 만듭니다(없으면 지금의 데모 녹화).

- 휴대폰 · PC 를 **같은 시각축 하나로 그대로 재생** — 자르거나 늦추지 않습니다. 표기: "운영 서버 · 가상 기업 · 두 화면 동시 녹화 · 편집 없음"
- 오른쪽 판은 "운영 서버 — 새로고침 없이 반영": 받는 화면이 바뀌는 순간마다 잰 초(예: "고객 제출 1.4초 뒤 · 새로고침 없음") + 시스템이 남긴 이력 한 줄
- 나레이션과 어긋나면 `build.py` 가 필요한 쉼을 계산해 멈춥니다 → `pauses_new.json` 을 `pauses.json` 으로 옮기고 `align_voice.py` → `build.py` → 렌더

```bash
python3 tools/video/appeal/build.py $W            # 쉼 조정 필요 → cp $W/pauses_new.json tools/video/appeal/pauses.json
W=$W python3 tools/video/appeal/align_voice.py $W/v2/voice_raw14.wav $W/v2/asr.json && python3 tools/video/appeal/build.py $W
node tools/video/appeal/render.mjs video $W/comp.html $W/voice.wav $W/out.mp4
```

다른 장면 · 자막 · 디자인 · 순서는 그대로이고, 시각만 새 나레이션에 맞춰 다시 계산됩니다.
