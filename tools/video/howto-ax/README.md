# KPJK AX 사용 방법 영상 (9:16, 자막, 약 3분 43초)

`../VIDEO_STYLE_GUIDE.md` 규격, 만드는 순서는 `../reel-ax/README.md` 와 같습니다 (받아쓰기 → 쉼 줄이기 → 1.1배속 → 자막 정렬 → 캡처 → 장면 → 렌더).
`asr.py` · `trim.py` · `align.py` 는 `../reel-ax/` 것을 그대로 씁니다. 받아쓰기 오류는 `align.py` 에서 고칩니다 (이번: "보안이" → "보완이", "추가 제한" → "추가 제안").

| 파일 | 하는 일 |
|---|---|
| `chunks.txt` | 자막 조각 84개 (한 줄 16자 이하) |
| `capture.mjs` | 데모 모드에서 기업 등록 창, 자료 요청(법인등기부등본 실제 등록), 휴대폰 제출(사진 찍어 올리기), 업무 자동 생성, 검토, 고객 반영, 고객의 상담 요청 → 업무함, 지원사업 화면 캡처 |
| `comp.html` | 장면 구성 (사용 방법 5단계 → 기대 변화 → 한 사이클부터 시작 → 목적) |
| `render.mjs` | 시험 프레임 / 전체 렌더 → `out/howto-ax/KPJK_AX_사용방법.mp4` |

앱에서는 사이드바 `AX 코치` 와 `설정` 사이 **사용 방법 영상**(`/ax/howto`) 으로 볼 수 있습니다 (`public/media/kpjk-ax-howto.mp4`).
