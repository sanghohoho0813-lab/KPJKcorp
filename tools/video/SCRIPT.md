# KPJK Business AX 영상 대본

두 영상 모두 **실제로 작동하는 화면을 그대로 녹화**했습니다. 편집으로 만든 결과 화면은 없습니다.
화면 속 기업명·수치는 시연용 샘플 데이터이며, 영상 내내 오른쪽 아래에 그 사실이 표시됩니다.

---

## 영상 1 — 실사 담당자용 (1:00)

`KPJK_AX_실사용_60초.mp4` · 1920×1080 · 소리 없음(자막형)

소리 없이 봐도 이해되도록 자막만으로 구성했습니다. 실사 자리에서 틀 때는 대표님이 옆에서 말로 보태시면 됩니다.

| 시간 | 화면 | 자막 |
|---|---|---|
| 0:00 | 타이틀 | 경영컨설팅 운영을 하나의 데이터 흐름으로 |
| 0:04 | 도입 전 업무 흐름 7단계 (Why AX 화면과 같은 내용) | 고객이 늘수록 "그 자료 받았나? 어디까지 됐지?" 확인하는 시간이 컨설팅 시간을 잠식했습니다 |
| 0:11 | 기업고객 → 에이정밀(주) 상세 | 고객 한 곳을 중심으로 상담·계약·프로젝트·자료·일정이 모입니다 |
| 0:18 | **고객 Portal** — 보완요청 받은 자료 재제출 | 보완 요청을 받은 고객이 Portal에서 직접 재제출합니다 → 제출하면 담당 컨설턴트에게 바로 전달됩니다 |
| 0:27 | **담당자 업무함** — 검토 업무 자동 생성 | 제출 즉시 담당자 업무함에 검토 업무가 자동으로 생깁니다 |
| 0:31 | **자료관리** — 검토 완료 | 담당자는 방금 올라온 파일을 열어 확인하고 → 검토 완료 한 번이면 고객 화면까지 바뀝니다 |
| 0:38 | **고객 Portal** — 확인완료 반영 | 고객 화면이 확인완료로 바뀌고, 알림이 갑니다 |
| 0:43 | 대표 대시보드 | 대표는 출근하면 오늘 먼저 확인할 것을 근거와 함께 봅니다 |
| 0:49 | Evidence Log — 방금 처리가 기록된 모습 | 고객 제출 → 업무 자동 생성 → 검토 완료가 순서대로 남습니다 → 기준선과 실측을 나눠 측정 — 개선율은 실측 뒤에만 표시합니다 |
| 0:56 | 마무리 | 대표·담당자·고객 권한 분리 / PC와 휴대폰에서 같은 화면 / 모든 처리 이력 기록·CSV 내보내기 |

**0:18 ~ 0:43 이 핵심입니다.** 고객 제출 → 자동 업무 생성 → 검토 → 고객 화면 반영이 한 번에 이어지는 것을
실제 조작으로 보여 줍니다. 0:49 의 기록 화면에는 방금 영상에서 한 처리 3건이 행위자·시각과 함께 찍혀 있습니다.

**일부러 넣지 않은 것** — 개선율·절감시간·ROI. 아직 실측 데이터가 없기 때문입니다. 대신
"개선율은 실측 뒤에만 표시한다"는 원칙을 자막으로 밝혔습니다. 심사자에게는 숫자보다 이 문장이 신뢰를 줍니다.

## 영상 2 — 대표·직원용 튜토리얼 (2:00)

`KPJK_AX_튜토리얼_2분.mp4` · 1920×1080 · 자막형

회의실에서 함께 틀어 놓고 보는 용도입니다. 목소리를 입히려면 아래 **내레이션**을 그대로 읽거나
클로바더빙 같은 음성합성에 붙여 넣으세요. 각 줄은 해당 장면 길이 안에 들어가도록 맞췄습니다(보통 속도 기준).

| 시간 | 장면 | 화면에서 하는 일 | 내레이션 |
|---|---|---|---|
| 0:00 | 타이틀 | — | KPJK 비즈니스 AX 사용법, 2분이면 됩니다. |
| 0:04 | ① 출근 | 로그인 → 오늘 확인할 일 | 출근하면 아이디와 비밀번호로 로그인합니다. 첫 화면은 '오늘 확인할 일'입니다. 빨간 숫자가 있는 카드부터 눌러서 처리하세요. |
| 0:16 | ② AI 브리핑 | 왜? → 리마인드 초안 → 복사 | AI 브리핑엔 급한 일이 근거와 함께 순서대로 정리됩니다. 버튼 한 번이면 고객에게 보낼 안내문 초안이 나오고, 복사해서 카톡으로 보내면 끝입니다. |
| 0:29 | ③ 새 고객 | 기업고객 등록 → 예시기업(주) | 새 고객은 '기업고객 등록'에서 시작합니다. 사업자등록증을 올리면 기본 정보가 자동으로 채워지고, 나머지는 클릭으로 고르면 됩니다. |
| 0:45 | ④ 자료 요청 | 프로젝트 → 자료 요청 | 프로젝트 화면에서 '자료 요청'을 누르고 자료 이름과 기한만 적으세요. 고객 포털에 바로 뜨고, 기한을 사흘 넘기면 독촉 업무가 자동으로 생깁니다. |
| 0:57 | ⑤ 고객 화면 | 고객 Portal → 방금 요청한 자료 제출 | 고객은 로그인하면 진행상황부터 봅니다. 방금 요청한 자료가 여기 떠 있고, 고객이 직접 파일을 올립니다. 카톡이나 메일로 따로 받을 필요가 없습니다. |
| 1:12 | ⑥ 검토 | 업무함 자동 업무 → 자료관리 → 검토 완료 | 고객이 올리면 업무함에 검토 업무가 자동으로 생깁니다. 파일을 열어 확인하고 검토 완료나 보완 요청을 누르세요. 결과는 고객에게 알림으로 갑니다. |
| 1:27 | ⑦ 고객 문의 | 초안 제안 → 답변 등록 | 고객 문의는 업무함의 '고객 문의' 탭에 모입니다. '초안 제안'으로 답변을 시작해서 다듬고, 등록하면 고객 포털에 그대로 보입니다. |
| 1:39 | 휴대폰 | 실제 휴대폰 화면 | 휴대폰에서도 똑같이 쓸 수 있습니다. 이동 중에 확인하고 승인하세요. |
| 1:47 | 처음 2주 | 대시보드 → 실증 시작 | 처음 2주는 AX 코치가 오늘 할 일을 하루 세 개 이내로 알려 줍니다. |
