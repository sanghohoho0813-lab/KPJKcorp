# 사업자등록증 인식 벤치마크

지어낸 값(검증번호만 국세청 규칙에 맞춤)으로 사업자등록증 그림을 만들고, **실제 앱의 기업고객 등록 화면**에 올려 칸마다 맞았는지 셉니다.
실제 고객 서류는 쓰지 않습니다.

- `gen.mjs` — 법인 8 · 개인 4 양식 × (620px 저해상도 + 워터마크 / 1000px · 기울기) + 텍스트 PDF 1 = 25장, `truth.json`
- `bench.mjs` — 앱(`npm start`, 데모 모드)에 로그인해 한 장씩 올리고 칸별 정확도 출력

준비: `/var/tmp/ocrbench` 에서 `npm i @fontsource/nanum-gothic @fontsource/nanum-myeongjo` (시험용 글꼴), 글자 인식 언어 데이터
`kor/eng.traineddata.gz` 를 `/var/tmp/ocr/` 에 둡니다(샌드박스는 CDN 이 막혀 로컬에서 줍니다).
